# NexumID NFC LAB · APK Android
Aplicación de diagnóstico NFC: lectura pública de tarjetas NFC, compatibilidad MIFARE Classic y HCE ISO-DEP de laboratorio.
**No es una credencial de acceso Hikvision ni un clonador de MIFARE Classic.** Mantener la tarjeta física y usar el celular requiere una credencial móvil administrada por el responsable de seguridad y un lector Hikvision compatible.
Compilación: GitHub Actions `NexumID NFC LAB APK`, artifact `NexumID-NFC-LAB-0.1.1-instalable`. Instalar el `app-debug.apk` en el Motorola.
